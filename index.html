Model Context Protocol (MCP)
для экосистемы 1С:Предприятие

Легковесный открытый мост, предоставляющий AI-агентам (Claude 3.5, Cursor, Windsurf) безопасный доступ к стандартному OData REST интерфейсу 1C:ERP, 1C:УНФ и 1С:УТ в строгом соответствии с 152-ФЗ.

Быстрый старт Enterprise-внедрение

Топология взаимодействия

1. AI Agent Client

Claude Desktop, Cursor, IDE Copilot формируют JSON-RPC запросы по спецификации MCP.

2. 1C-OData-MCP Core

Python-обвязка валидирует $filter, нормализует схемы номенклатуры и ограничивает $top выборки.

3. 1C OData REST v3

Платформа 1С 8.3 обрабатывает запросы с проверкой RLS прав пользователя базы.

Конфигурация в 3 шага

1. Клонирование репозитория

git clone https://github.com/Vlad-Voro/1c-odata-mcp.git
cd 1c-odata-mcp
python mcp_server.py --manifest

2. Добавление в Claude Desktop Config

{
  "mcpServers": {
    "1c-odata": {
      "command": "python",
      "args": ["/abs/path/to/1c-odata-mcp/mcp_server.py"],
      "env": {
        "ONEC_ODATA_URL": "http://1c-server/erp-base",
        "ONEC_AUTH_BASE64": "dXNlcjpwYXNzd29yZA=="
      }
    }
  }
}
